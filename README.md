# КИН-ДЗА-ДЗА VPN — установщик origin-сервера

Скрипт разворачивает VPN-сервер за CDN на чистом Ubuntu-сервере. Продаётся по ключу через Telegram-бота [@kdz3xui_bot](https://t.me/kdz3xui_bot).

## Что делает скрипт

- Берёт чистый сервер Ubuntu 22.04/24.04 и за несколько минут доводит его до рабочего узла: TLS-сертификат, nginx, фаервол, панель 3x-ui, готовые инбаунды VLESS+XHTTP.
- Настраивает сервер на работу через CDN — с корректным определением IP клиентов на стороне сервера.
- В конце печатает адрес панели, логин, пароль и ссылку подписки. Никакой ручной возни с конфигами.

## Как получить и использовать

1. Купить ключ в боте [@kdz3xui_bot](https://t.me/kdz3xui_bot) — кнопка «🔑 Купить ключ».
2. Взять чистый сервер Ubuntu 22.04 или 24.04 с доступом root.
3. Завести домен с A-записью на этот сервер (режим DNS only) и отдельный домен для CDN-ресурса.
4. Подключиться по SSH под root и выполнить одной строкой:

   ```
   curl -sL kdz3xui.kindzadza.org/go | bash
   ```

   Если на сервере нет `curl`:

   ```
   wget -qO- kdz3xui.kindzadza.org/go | bash
   ```

5. Ввести ключ, когда его спросят. Дальше скрипт всё сделает сам.

## Важно знать до установки

- **Скрипт полностью очищает сервер** перед установкой — используйте только чистый или ненужный сервер.
- Ключ вводится один раз, сохраняется на сервере и рассчитан на 20 серверов; сколько использовано — скрипт показывает при каждом запуске.
- Проверка ключа идёт через сервер активации: без связи с ним скрипт не запустится.
- Обычный читаемый bash-файл — ничего не скомпилировано. Сам код выдаётся только после оплаты и лично покупателю, поэтому исходник не публикуется здесь в открытом виде.
- Работоспособность зависит от вашего хостинга, домена и настроек CDN — это вне нашего контроля.

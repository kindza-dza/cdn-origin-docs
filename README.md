# КИН-ДЗА-ДЗА VPN — установщики VPN-серверов

Скрипты разворачивают VPN-сервер на чистом Ubuntu-сервере. Продаются по ключу через Telegram-бота [@kdz3xui_bot](https://t.me/kdz3xui_bot). Три тарифа — выбираете при покупке ключа.

## Тарифы

### CDN origin-сервер
Сервер за российским CDN: сертификат, nginx, фаервол, панель 3x-ui, инбаунд VLESS + XHTTP. Нужны два домена — origin и для CDN-ресурса.

### Три инбаунда на одном порту (443)
Прямое подключение к серверу, без CDN: все три протокола снаружи на одном порту 443 — VLESS + XHTTP + Reality и VLESS + Vision + Reality (tcp) и Hysteria2 (udp). nginx по имени в TLS-запросе раздаёт соединения, не вскрывая шифрование, а на обычный заход по вашему домену открывается сайт-прикрытие — один из десяти информационных сайтов, выбирается случайно при установке. Панель 3x-ui на порту 8443, в ней видны настоящие IP клиентов. Нужен один домен.

### Три инбаунда
Прямое подключение к серверу, без CDN: панель 3x-ui и сразу три готовых инбаунда — Hysteria2, VLESS + Vision + Reality и VLESS + XHTTP + Reality — на одном клиенте. Нужен один домен (только для сертификата Hysteria2).

## Что общего у всех скриптов

- Берут чистый сервер Ubuntu 22.04/24.04 и за несколько минут доводят его до рабочего узла — без ручной возни с конфигами.
- В конце печатают адрес панели, логин, пароль и ссылку(и) подписки.
- Ключ вводится один раз, сохраняется на сервере и рассчитан на 20 серверов; сколько использовано — скрипт показывает при каждом запуске.
- Проверка ключа идёт через сервер активации: без связи с ним скрипт не запустится.
- Обычный читаемый bash-файл — ничего не скомпилировано. Код выдаётся только после оплаты и лично покупателю, поэтому исходник не публикуется здесь в открытом виде.
- **Скрипт полностью очищает сервер** перед установкой — используйте только чистый или ненужный сервер.
- Работоспособность зависит от вашего хостинга, домена и (для CDN-тарифа) настроек CDN — это вне нашего контроля.

## Как получить и использовать

1. Открыть бота [@kdz3xui_bot](https://t.me/kdz3xui_bot) → «🔑 Купить ключ» → выбрать тариф.
2. Взять чистый сервер Ubuntu 22.04 или 24.04 с доступом root.
3. Завести домен(ы) с A-записью на этот сервер (режим DNS only) — какие именно, см. в тарифах выше.
4. Подключиться по SSH под root и выполнить одной строкой:

   ```
   curl -fsSL kdz3xui.kindzadza.org/go | bash
   ```

   Если на сервере нет `curl`:

   ```
   wget -nv -O- kdz3xui.kindzadza.org/go | bash
   ```

5. Ввести ключ, когда его спросят — скрипт сам поймёт, какой тариф вы купили, и запустит нужную установку. Если на сервере уже сохранён ключ от прошлой установки, скрипт предложит его: Enter — продолжить с ним, или введите новый ключ (например, от другого тарифа).
